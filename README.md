# Dragon Realm — stable-web-v1

Website-first prototype for an original dragon collection and city-building game.

## Current features

- Interactive island building grid
- Gold, food and gems economy
- Realm XP and leveling
- Fire, Water, Nature and Earth habitats
- Farms and resource collection
- Starter dragon collection
- Dragon feeding and leveling
- Browser save system using localStorage
- Responsive desktop/mobile layout

## Run locally

Open `index.html` in a modern browser.

## Stable baseline

This repository starts from `stable-web-v1`. Future gameplay systems will be added incrementally without replacing the stable core until tested.
